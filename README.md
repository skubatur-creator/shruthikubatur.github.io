# Faculty website

Plain HTML and CSS. No build step.

## Deploy on GitHub Pages
1. Create a public repository named `<your-github-username>.github.io`.
2. Copy every file in this folder into the repository root and push.
3. In the repository, go to Settings > Pages and confirm the source is the `main` branch, root folder.
4. The site is live at `https://<your-github-username>.github.io` within a few minutes.

## Custom domain (optional)
Add a file named `CNAME` containing your domain, and point the domain's DNS at GitHub Pages.

## Editing
- Text: edit the HTML files directly.
- New publication: copy one `<li>` block in `publications.html`.
- Colors and type: `style.css`, top of the file.
- CV: replace `assets/cv.pdf`.
